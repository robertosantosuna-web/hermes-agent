# v11.2 Final Configuration (29/05/2026)

## Pipeline
Multi-TF Bias (W/D/H4) → CRT filter (opcional) → FVG M1 + candle fechado → DMI(M1) + ATR(M5) → RR 3:1

## Filters
- **SL**: ATR(14) no M5 × 1.5, clamp 10-30p forex / 200-300t XAU
- **DMI**: DMI(14) no M1 — exige alinhamento com bias (pdi>ndi para BUY, ndi>pdi para SELL)
- **Volume**: > 1.3× média móvel (20)
- **Candle**: fechado obrigatório (índice < len-1)
- **Anti-corr**: MAX_CORRELATED=1 por moeda base (USD: USDJPY+USDCAD, EUR: EURUSD+EURJPY, GBP_XAU: GBPUSD+GBPJPY+XAUUSD)

## Trade Management
- **RR**: 3:1 fixo
- **Risco**: 0.5% fixo por trade
- **2R**: SL → breakeven
- **3R**: SL → +1.5R trail

## Data Sources
- **M1**: CDP TradingView Brave :9222 WebSocket (tv_ohlc_extractor.py) → ~544 velas
- **M5**: yfinance (para ATR)
- **1d/4h**: yfinance (para Multi-TF Bias)
- **Fallback M1**: yfinance se CDP falhar
