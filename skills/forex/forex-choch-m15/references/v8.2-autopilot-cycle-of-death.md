# V8.2 — AutoPilot Cycle of Death (27/05/2026)

## Symptom

Forex orders opening and closing in rapid sequence:
- Multi-Strategy Bot opens 5 orders every 15 minutes
- AutoPilot closes ALL positions every 5 minutes
- 154 trades in a single morning
- Balance dropping from $400 → $374
- None hitting take profit

## Root Cause

**AutoPilot had hardcoded $400 initial balance with 3% drawdown threshold:**

```python
# ❌ BROKEN
drawdown_pct = (1 - equity / 400) * 100  # assume $400 initial
if drawdown_pct > 3:                      # 3% = $12 loss
    close_all()
```

With equity at $370: drawdown = (1 - 370/400) × 100 = 7.5% → triggers every tick.

The threshold of 3% ($12) is calibrated for forex SL (~$1.50) but with 5+ positions open each tick, the floating loss naturally exceeds $12.

**Cycle:**
1. Bot opens 5 orders (XAUUSD, USDCAD, GBPUSD, GBPJPY, USDJPY) at T+0
2. AutoPilot runs at T+5: sees DD > 3%, closes all
3. Bot opens 5 more at T+15
4. AutoPilot closes at T+20
5. Repeat indefinitely

## Fixes Applied (27/05/2026)

### 1. Dynamic Balance Detection
```python
# ✅ FIXED
initial_balance = balance  # Read REAL balance from MT5
state_file = FOREX / 'autopilot_state.json'
if state_file.exists():
    initial_balance = json.loads(state_file.read_text())['initial_balance']
else:
    state_file.write_text(json.dumps({'initial_balance': balance}))

drawdown_pct = (1 - equity / max(initial_balance, 1)) * 100
if drawdown_pct > 15:  # 15% DD threshold (was 3%)
    close_all()
```

### 2. Cooldown After Mass Close
```python
# After close_all, write cooldown file
(FOREX / 'autopilot_cooldown').write_text(str(datetime.now()))

# Before any action, check cooldown
cooldown_file = FOREX / 'autopilot_cooldown'
if cooldown_file.exists():
    last_close = datetime.fromisoformat(cooldown_file.read_text().strip())
    if (datetime.now() - last_close).total_seconds() < 1800:  # 30 min
        sys.exit(0)  # Skip this tick
```

### 3. Daily Trade Limit in Bot
```python
# ✅ NEW in forex_bot_multi.py
MAX_DAILY_TRADES = 20
today = datetime.now().strftime('%Y-%m-%d')
trades_hoje = sum(1 for t in tlog_data.get('trades', []) 
                  if str(t.get('timestamp', '')).startswith(today))
if trades_hoje >= MAX_DAILY_TRADES:
    print(f"⛔ Limite diário atingido ({trades_hoje}/{MAX_DAILY_TRADES})")
    return
```

## Prevention Rules

- **AutoPilot DD threshold must be ≥ 15%** — 3% was calibrated for single-position scenarios, not multi-position bot
- **Always read real balance from MT5** — never hardcode initial balance
- **Always cooldown after mass close** — prevents immediate re-entry
- **Bot must have daily trade limit** — MAX_DAILY_TRADES prevents overtrading
- **Monitor trade count per session** — 154 trades/day is a red flag
