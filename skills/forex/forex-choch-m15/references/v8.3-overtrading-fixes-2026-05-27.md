# V8.3 Critical Overtrading Fixes — 27/05/2026

## Symptom

Bot abriu **172 trades em um dia** com conta de $400. Balance caiu de $447.90 → $363.41 (-18.8%) em 3 horas. N. Accumbens nunca processou trades reais. Trade log mostrava só 2 WINS enquanto MT5 executou 172 ordens.

## Root Cause: 4 Critical Bugs

### Bug 1: Daily trade limit NEVER activated (timestamp vs time mismatch)
```python
# O código procurava 'timestamp' mas o bot salva 'time'
trades_hoje = sum(1 for t in data['trades'] 
                  if str(t.get('timestamp', '')).startswith(today))
#                              ^^^^^^^^^ 
# Sempre retornava 0 → limite diário nunca ativou
```
**Fix:** `str(t.get('timestamp', t.get('time', ''))).startswith(today)`

### Bug 2: Zero duplicate position protection
O bot abria novos trades nos MESMOS pares a cada ciclo de 15min. Não verificava se o símbolo já tinha posição aberta no MT5.
**Fix:** `open_symbols` set from MT5 positions; check `pair_symbol in open_symbols` before executing.

### Bug 3: MAX_POSITIONS=8 with $400 account
Cada trade arriscava 2% ($8). 8 posições = $64 de risco simultâneo (16% da conta).
**Fix:** MAX_POSITIONS: 8 → 4.

### Bug 4: Trade log ghost — `record_trade()` imported but NEVER called
`record_trade` was imported from `trade_tracker` but never invoked in the execution flow. `trade_log.json` had only manually-tracked trades while MT5 executed hundreds.
**Fix:** Added `record_trade()` call after each successful `send_order`.
