# V8.5 Analysis Pipeline (27/05/2026)

Three-stage analysis pipeline for forex trading decisions. Replaces the old browser/CDP-dependent approach.

## Pipeline Order

```
1. Range Detector → "QUANDO operar"
2. Flow + Trend  → "DIREÇÃO e FORÇA"  
3. Chart Analyzer → "ONDE entrar" (FVG + CRT + S/R)
```

## Stage 1: Range Detector (`range_detector.py`)

Detects if a pair is ranging or trending using:
- ADX (threshold: <25 = range, >30 = trend)
- BB Squeeze detection
- ATR ratio (current volatility vs baseline)
- Multi-TF consolidation scoring (M15→M30→H1→H4)

**Rule:** ADX < 25 in the primary TF → SKIP the pair entirely. Ranging pairs kill FVG strategies.

```bash
python3 ~/.hermes/scripts/range_detector.py          # All pairs
python3 ~/.hermes/scripts/range_detector.py GBPJPY   # Single pair
```

Output saved to `~/.hermes/forex/range_detector.json`.

## Stage 2: Flow + Trend (`flow_trend.py`)

Analyzes order flow and trend structure across M15, M30, H1, H4:

**Flow metrics:**
- Bull/Bear candle ratio
- CVD (Cumulative Volume Delta) simulated from price action
- Volume-weighted momentum
- Absorption detection (large candle + reversal)

**Trend metrics:**
- HH/HL structure detection (uptrend) vs LH/LL (downtrend)
- ADX trend strength
- EMA20 vs EMA50 direction
- Trend maturity (candles since last structure break)

**Decision criteria:**
- Consensus > 70% + Flow > 0.1 → 🟢 SETUP CONVICTIVO
- Trend > 0.5 + Flow > 0.3 → 🟢 SETUP 
- Consensus > 50% + Trend > 0.4 → 🟡 MODERADO
- Trend < 0.3 + Flow < 0.15 → ⚪ LATERAL

```bash
python3 ~/.hermes/scripts/flow_trend.py GBPJPY       # Single pair
python3 ~/.hermes/scripts/flow_trend.py --all         # All 6 pairs
```

## Stage 3: Chart Analyzer (`chart_analyzer.py`)

Multi-timeframe FVG + CRT + S/R analysis. Detects entry points with scoring:

- FVG detection (Gap ≥ 2 pips)
- CRT percentile (current candle position in recent range)
- S/R levels (swing highs/lows)
- Quality scoring (gap size × recency × CRT)

**Rule:** Only enter when CRT ≥ 70% AND dominance ≥ 65%. Zero forced entries.

```bash
python3 ~/.hermes/scripts/chart_analyzer.py GBPJPY    # Single pair
python3 ~/.hermes/scripts/chart_analyzer.py --all      # All pairs
```

## Backtest Pipeline

### V1 (FVG+CRT raw): 652 trades, 31.9% WR, -2071p
Too many signals, no quality filters.

### V2 (Quality filters): 28 trades, 35.7% WR, +49p
Gap≥10p, CRT≥85%, Dominance≥80%, Trend alignment, Max 1/day/pair.
USDJPY 100% WR, EURJPY 66.7% — only profitable pairs.

### V3 (Unified + Range filter): 32 trades, 34.4% WR, -16p
Added ADX<25 range skipping. 818 candles skipped.
Market-wide ranging conditions reduced profitability.

**Lesson:** FVG+CRT standalone does NOT work as autonomous strategy. Pair with range detection and flow analysis for signal confirmation.

## Data Source

**TvDatafeed (TradingView) — PRIMARY.** Returns 3-6x more FVGs than yfinance.
Columns: lowercase `open`, `high`, `low`, `close` (NOT uppercase like yfinance).
Installed via: `pip install git+https://github.com/rongardF/tvdatafeed.git`

```python
from tvDatafeed import TvDatafeed, Interval
tv = TvDatafeed()
df = tv.get_hist(symbol='GBPJPY', exchange='FX', interval=Interval.in_15_minute, n_bars=200)
```

yfinance is fallback only.
