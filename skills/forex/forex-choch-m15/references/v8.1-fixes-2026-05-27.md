## XAUUSD Precision Fix

**Problema:** `calculate_sl_tp()` usava `round(sl, 5)` para todos os pares. XAUUSD tem 2 dígitos decimais no MT5. Preços com 5 decimais (ex: 4495.60010) são rejeitados pelo broker.

**Correção:**
```python
def calculate_sl_tp(direction, entry, sl_pips, rr, pip_size, is_metal=False):
    decimals = 2 if is_metal else 5  # Metais: 2 decimais
    return round(sl, decimals), round(tp, decimals)
```

Chamada em `execute_trade()`:
```python
is_metal = 'XAU' in pair.upper() or 'GOLD' in pair.upper()
sl, tp = calculate_sl_tp(..., is_metal=is_metal)
```
